# Enhancement proposals

KEP/RFC-style proposals for larger changes and milestone plans. Start one by copying
`../templates/proposal.md` into `draft/` with the next free number. Accepted proposals move
to `accepted/` and are frozen (ADR-0003). This index is the authoritative record of each
proposal's current status and supersession (ADR-0004).

**What deserves a proposal:** work that spans several pull requests, changes how components
interact, or defines a milestone. A bug fix or a contained feature doesn't need one; an
issue is enough. The first proposal is usually **0001, the implementation arc**: the
milestones in build order, each with what it proves, the risk it retires, what it needs and
when it is done. Examples: wyrd's
[implementation arc](https://github.com/getwyrd/wyrd/blob/main/docs/design/proposals/accepted/0013-implementation-arc-rescoped.md)
and its [proposal index](https://github.com/getwyrd/wyrd/blob/main/docs/design/proposals/README.md).
